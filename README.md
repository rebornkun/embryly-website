# Embryly website preview

Static HTML, CSS and JavaScript. Run `python3 -m http.server 4317 --bind 127.0.0.1` and open http://127.0.0.1:4317.

The HTML pages are generated by `python3 build.py`; styles and interaction code are in `assets/`. Screens use fictional sample data from the app.

This is an uncommitted review draft. Do not deploy until the owner approves the design, confirms pricing, App Store URL and company details, and reviews the policy and app privacy gaps in `docs/REVIEW-BEFORE-PUBLISHING.md`. Preview pages are intentionally noindex and robots-disallowed.
